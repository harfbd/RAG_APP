07 / ARCHITECTURE

前端、後端與模型
各自負責什麼？

系統採手機可用的 PWA 原型，後端 API 負責檢索、生成與紀錄。外部服務各有明確角色，金鑰只放在伺服器端。

01 / 使用者端

手機 PWA

輸入問題、上傳照片、閱讀回答、查詢歷史與天氣。

→
02 / 應用後端

Vercel API

接收請求、讀取知識庫、整合檢索與生成結果。

→
03 / 語意檢索

Gemini

把問題轉為向量，與 277 個手冊段落進行相似度比對。

→
04 / 回答生成

Groq · Llama

根據檢索內容產生繁體中文建議並整理引用。

服務在系統中的角色資料性質
Gemini embedding語意向量與手冊檢索核心
Groq Llama 3.3依據檢索內容整理回答核心
Tavily提供網路搜尋補充補充
Open-Meteo顯示所在地天氣資訊情境
BigDataCloud將定位轉為中文地名情境
◎

DESIGN RULE

金鑰留在後端

手機只呼叫專題的後端端點。模型與搜尋服務金鑰透過伺服器環境變數讀取，避免直接寫入前端程式。
